# VYRAQ AI — Predict. Prepare. Protect.

A student-built interactive disaster preparedness learning experience. The project explores flood, earthquake and cyclone scenarios, risk signals, emergency readiness, and the AI Project Cycle.

## Development

The application source is in `app/`. It uses React, TanStack Start, Vite and Cloudflare Workers. See `app/package.json` for scripts and dependencies.

## Accessibility

Motion effects respect the user's reduced-motion preference.
